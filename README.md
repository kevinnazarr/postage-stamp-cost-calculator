# Postage Stamp Cost Calculator

A simple, single-page postage calculator for small crafts sellers. No frameworks, no backend — just HTML, CSS, and vanilla JavaScript.

## Features

- Enter package weight in **ounces**
- Choose from 3 mail types: First-Class Letter, First-Class Large Envelope, Priority Mail Flat Rate
- Instant cost breakdown: base rate, weight overage, total
- Last 5 calculation history (in-memory only)
- Clear History button
- Responsive design for desktop and mobile
- No backend, no database, no external APIs

## Usage

Open `index.html` in any browser.

## Rate Table

Rates are fixed example values hardcoded in `script.js`. Edit the `RATE_TABLE` object to update rates. These are **not** live USPS rates — they are example values for demonstration purposes.
