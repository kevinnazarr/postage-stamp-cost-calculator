# Kalkulator Biaya Ongkos Kirim

Kalkulator ongkos kirim sederhana untuk penjual kerajinan kecil. Tanpa framework, tanpa backend — hanya HTML, CSS, dan JavaScript vanilla.

## Fitur

- Masukkan berat paket dalam **ounce**
- Pilih dari 3 jenis layanan: Surat Biasa First-Class, Amplop Besar First-Class, Priority Mail Flat Rate
- Rincian biaya instan: tarif dasar, biaya kelebihan berat, total
- Riwayat 5 perhitungan terakhir (hanya dalam memori)
- Tombol Hapus Riwayat
- Desain responsif untuk desktop dan mobile
- Tanpa backend, tanpa database, tanpa API eksternal

## Cara Pakai

Buka `index.html` di browser apa pun.

## Tabel Tarif

Tarif adalah nilai contoh tetap yang ditulis langsung di `script.js`. Edit objek `RATE_TABLE` untuk mengubah tarif. Ini **bukan** tarif USPS resmi — melainkan nilai contoh untuk keperluan demonstrasi.
